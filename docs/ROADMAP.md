# Roadmap

## Foundation

- Standalone Codex and Git project.
- Lazy H3 loader, validated generation config, T2VA generation, and unload node.
- Tests, linting, licensing, and strict dependency boundaries.

## Kijai-style workflow surface

- First-frame, last-frame, and combined conditioning nodes.
- Multi-image, video, and audio reference builders.
- Separate transformer, VAE, and text-encoder controls.
- Model information, memory estimate, and workflow validation nodes.

## Apple Silicon performance

- Quantized checkpoint builder and loader nodes.
- AdaLN precompute controls and cache reporting.
- Step-cache experiments with exact fallback behavior.
- Preview decoding and cancellation.

## Advanced workflows

- Chained generation and overlap-aware stitching.
- Reference-to-video workflows.
- Reproducible benchmarks across Mac memory tiers.
- ComfyUI Manager packaging after node contracts stabilize.
