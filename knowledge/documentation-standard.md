# Documentation standard

Use controlled technical English selectively. Apply the strict profile to procedures, workflow
examples, node text, warnings, and errors. Apply the flexible profile to research, audits,
architecture notes, and benchmarks.

Apply the strict profile to every OKF concept. An OKF research concept is a controlled retrieval
summary; its canonical research document can use flexible technical prose. Separate claims,
evidence, limitations, and required validation when those distinctions improve retrieval.

The profile favors one term for each concept, explicit conditions, direct instructions, and clear
error recovery. It preserves exact MLX, Metal, MiniMax H3, Python, and ComfyUI terminology when
simpler wording would reduce precision. The project does not claim ASD-STE100 compliance.

The canonical rules and controlled terminology are in the [documentation standard](../docs/DOCUMENTATION.md).
